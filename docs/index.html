ViewTopia

Unified geospatial viewer combining TileTopia's 3D globe with GeoLang's AI-powered spatial analysis

View on GitHub Get Started

Features

🌍

3D Globe

CesiumJS with deck.gl and MapLibre GL renderer support. Fly anywhere, load 3D Tiles, terrain, and point clouds.

🗺️

2D Map

Leaflet-powered map with GeoJSON layers, marker clustering, choropleth styling, and interactive popups.

🤖

AI Chat Agent

Ask the GeoLang agent to analyze data, generate maps, compute isochrones, classify terrain — all in natural language.

💾

Session Persistence

Chat history persists across refreshes. Click any old response to instantly replay its map view.

📊

Multi-Format Data

Upload GeoPackage, GeoJSON, Shapefile, CSV, LAS/LAZ point clouds, GeoTIFF rasters, and glTF 3D models.

🎨

Multiple Renderers

Switch between CesiumJS, deck.gl, and MapLibre GL on the fly. Each with shared camera state and layer sync.

📐

Drawing & Measurement

Draw polygons, lines, rectangles on the 2D map. Measure distances and annotate points of interest.

📍

Click-to-Query

Click anywhere on the map to ask the AI about that location — elevation, flood risk, nearby amenities.

🔄

2D ↔ 3D Sync

Layers automatically sync between 2D Leaflet and 3D Cesium views. Camera position transfers on tab switch.

🗂️

Session Management

Create, switch, rename, and delete analysis sessions. Each session has its own agent memory and chat history.

🌙

Dark Theme

Beautiful dark interface optimized for map viewing with purple accent colors and smooth animations.

⌨️

Keyboard Shortcuts

Ctrl+B to toggle chat panel. Resizable panel with drag handle. Full-screen map when you need it.

Quick Start

# Clone the repo
git clone https://github.com/TileTopia-HQ/viewtopia.git
cd viewtopia

# Install dependencies
npm install

# Start dev server
npm run dev

# Open http://localhost:5174
# Backends are optional — viewer adapts to what's available
