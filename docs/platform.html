Platform Capabilities

22 open-source modules, Rust apart from the Python AI agent. One unified platform.

🤖

Natural Language Analysis

The GeoLang AI agent translates your questions into spatial operations. The agent loop runs in sibyl, which keeps each session's history in sqlite.

🎨

Answers that draw themselves

The agent answers with a map, a table or an image spec, and the viewer renders it in place. A layer the agent adds is an ordinary layer you can restyle, reorder and export.

🗄️

Enterprise Geodatabase

Git-like versioning for spatial data. Branch, commit, merge, diff. Role-based access, OIDC SSO, audit trails. PostGIS-powered.

🔬

Geoprocessing

19+ spatial analysis tools: buffer, clip, intersect, dissolve, voronoi, spatial join, nearest neighbor, distance matrix, and more.

🌐

3D / Digital Twin

3D Tiles, terrain, point cloud visualization. Indoor mapping with BLE/WiFi positioning. Real-time streaming for IoT/sensor data.

🚗

Routing & Navigation

Shortest path, isochrones, fleet optimization, indoor wayfinding with wheelchair-accessible routing. OpenStreetMap-powered.

📡

Field Collection

Custom forms, offline-first sync, photo/document attachments. Collect data in the field, sync to the geodatabase automatically.

📱

Mobile SDK

Rust mobile map core consumed from Kotlin over a flat C FFI. Camera and viewport math, gesture recognition, tile caching, offline feature storage, on-device turn-by-turn. Android only, and the host does the fetching and the drawing.

🛰️

AI/ML Imagery

Object detection, change detection, land classification on satellite and aerial imagery. Panoptes-powered computer vision.
